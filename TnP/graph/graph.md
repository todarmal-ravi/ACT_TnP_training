<h2>Types:</h2>
undirected and unweighted
undirected and weighted
directed and unweighted
directed and weighted

<p>directed: Source to destination, asymmetric</p>
<p>weighted: has units used for decision making eg. distance,length</p>

<h2>Applications:</h2>
Routing
biometric(security like face unlock)
searching(BFS and DFS)
topological sort(for each 'ith' state 'i-1' should be done, should be in a proper predefined order)
google maps(navigation)
social media

<p><b>degree</b> - number of edges the node is connected</p>
<p><b>out-degree</b> - number of edges leaving the node</p>
<p><b>in-degree</b> - number of edges entering the node</p>

blind search: (no unique answer)
DFS - vertical search, depth by depth, uses stack
BFS - horizontal search, breadth, level by level, use queue
